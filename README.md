# Ejecutar en Desarrollo

1. Clonar repositorio a través de GitHub

2. Comando para ejecutar

```bash
$ npm install
```
3. Es necesario tener Nest CLI instalado
```bash
$ npm i -g @nestjs/cli
```
4. Comando para levantar la BD-Nest-Servidor
```bash
$ docker-compose up -d
```
